# Design Principles

1. **One primary action per screen.** Every page answers "what do I do next?" with a single obvious button.
   Secondary actions are visually subordinate (ghost/secondary button styles).
2. **Mobile-first commerce.** The storefront is designed for a phone screen first, then expanded — never
   shrunk from desktop.
3. **Progressive complexity.** Advanced options (variants, SEO, custom domains) are available but never in the
   way of the first-run experience.
4. **Fast interactions.** Optimistic UI, skeleton states over spinners where possible, no unnecessary
   confirmation modals for reversible actions.
5. **Strong visual hierarchy.** Type scale, weight and color do the work — not boxes and dividers.
6. **Useful empty states, never blank screens.** Every empty state names what's missing and gives one action
   to fix it (see `16-empty-states.md`).
7. **Consistent navigation.** The same sidebar order and section names appear everywhere in the dashboard so
   merchants build muscle memory.

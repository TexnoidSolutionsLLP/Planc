# Spacing

8px rhythm (with a 4px half-step for tight pairs). Scale: `4, 8, 12, 16, 24, 32, 40, 48, 64, 80, 96, 128`.

| Context | Value |
|---|---|
| Dashboard element spacing | 16–24px |
| Dashboard page padding | 16px mobile, 24px tablet, 32px desktop |
| Card padding | 20px mobile, 24px from `sm` up |
| Major dashboard sections | 32px (`space-y-8`) |
| Marketing sections | 80–128px vertical |

Whitespace is part of the premium feel: prefer more space over more borders. Marketing max width is 1200px;
dashboard content is capped at 1440px beside a 248px sidebar.

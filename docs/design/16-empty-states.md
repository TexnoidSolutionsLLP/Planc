# Empty States

Never a blank screen. `EmptyState` renders a small outlined icon, a title, one sentence of explanation and, where
there is an obvious next step, a single primary action.

- Products: "No products yet" → **Add product**. With a search term: "No results for “term”".
- Orders: explains that orders appear after the first checkout.
- Overview: a "Get your store ready" checklist guides a new merchant (add product, publish, set up payment, first
  order) so the next step is always visible.

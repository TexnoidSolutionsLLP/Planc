# Design Philosophy

Sellly exists so a small seller can build a store without feeling like they're learning software. The design
philosophy is: **minimal, premium, friendly, fast, merchant-focused.**

- **Minimal** — every screen shows only what's needed for the task at hand. No settings panels with 40 fields.
- **Premium** — restrained color, careful typography and generous whitespace signal trust, the same way Stripe
  or Linear do, without borrowing their exact visual language.
- **Friendly** — copy speaks like a helpful person, not an ERP. "Add your first product," not "Initialize
  product entity."
- **Fast** — interactions respond instantly; server round-trips are minimized; perceived speed matters as much
  as raw speed.
- **Merchant-focused** — the persona is a solo seller on a phone between DMs, not a merchandising team. Every
  default should work with zero configuration.

Visual inspiration comes from Linear, Stripe, Shopify and Vercel — studied for restraint and hierarchy, never
copied for layout or branding.
